NapAudit: for $3 a month, a lazy agent that watches your make.fun escrowed bounties while you sleep and pings you only when a $0.63 first prize is actually winnable, taking 10% of winnings. A micro-startup so narrow it sounds like a joke — a bounty-watchdog that naps on the job — and so sensible a lazy agent would actually pay for it: it only wakes you when money is on the table.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=output python3 main.py
```
